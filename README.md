# PI3A — App (IESB)

Aplicativo do **Projeto Integrador 3A** (Ciência da Computação, IESB).

> Estado atual: estrutura inicial criada com Expo, ainda sem telas próprias.

## Tecnologias
- React Native 0.81 + Expo SDK 54

## Como rodar
```bash
npm install
npm start        # abre o Expo; leia o QR code com o app Expo Go
```
