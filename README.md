# 🎓 HelpIesb - Frontend

> Projeto desenvolvido para a disciplina de Projeto Integrador 3A (PI3A) - Aplicação de suporte e interação para alunos.

## 📱 Sobre o Projeto
O **HelpIesb** é um aplicativo voltado para o ambiente acadêmico, criado para centralizar ferramentas e facilitar a comunicação entre os estudantes. Este repositório contém a **interface base (Frontend)** construída a partir dos protótipos do Figma, utilizando componentes funcionais e navegação simulada.

## 🛠️ Tecnologias Utilizadas
* **React Native** (Estrutura do aplicativo)
* **Expo** (Ambiente de desenvolvimento e testes)
* **JavaScript** (Lógica de componentes)

## 📌 Telas Desenvolvidas
Nesta primeira entrega, o frontend contempla as seguintes estruturas visuais:
1. **Home (Início):** Dashboard de acesso rápido às ferramentas (Fórum, Notas, Atléticas, etc).
2. **Feed do Fórum:** Listagem de dúvidas e discussões da comunidade.
3. **Detalhes do Post:** Visualização de uma publicação específica e área de comentários.
4. **Nova Publicação:** Formulário para criação de novos tópicos no fórum.
5. **Perfil do Aluno:** Carteirinha digital e histórico de postagens.

## 🚀 Como Executar o Projeto

Certifique-se de ter o Node.js instalado em sua máquina.

1. Clone este repositório:
"git clone https://github.com/PedroMarra/PI3A_IESB.git"

2. Acesse a pasta do projeto:
"cd pi3a_iesb"

3. Instale as dependências:
"npm install"

4. Inicie o servidor do Expo:
"npx expo start"

5. Escaneie o QR Code com o aplicativo Expo Go no seu celular para visualizar o app.
